# AI-Driven E-Commerce Analytics

### AI-Powered End-to-End Data Analytics Workflow using Prompt Engineering, Python & Power BI

---

# Project Overview

This project demonstrates how Generative AI can enhance and accelerate the end-to-end data analytics workflow for an e-commerce business. Instead of performing repetitive analytical tasks manually, AI was used as a productivity assistant to automate data cleaning, exploratory data analysis (EDA), SQL query generation, dashboard planning, business insight generation, and report drafting.

The project highlights how AI and human expertise can work together to improve efficiency while maintaining analytical accuracy and business relevance.

# Business Problem

Traditional data analytics involves repetitive and time-consuming tasks such as:

* Data cleaning
* Exploratory Data Analysis (EDA)
* SQL query writing
* Dashboard planning
* Business insight generation
* Report documentation

The objective of this project is to demonstrate how Generative AI can streamline these activities while allowing analysts to focus on interpreting results and making strategic business decisions.
